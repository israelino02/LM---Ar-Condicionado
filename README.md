# LM Ar Condicionado

Site institucional de página única da LM Ar Condicionado, empresa de instalação, manutenção e
higienização de ar-condicionado em Saquarema, Araruama e municípios vizinhos da Região dos Lagos, RJ.

Site estático, sem build e sem dependência externa: um `index.html` com todo o CSS e o JS dentro,
mais a pasta `assets`. Publicado na Vercel a partir da branch `main`.
